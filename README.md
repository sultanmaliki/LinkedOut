# LinkedOut

LinkedOut is a parody/professional networking platform where companies apply to employees rather than the reverse. The platform helps professionals evaluate companies through transparency, culture, compensation, interview experience, growth opportunities, and community feedback.

## Project Status

This repository currently contains the initial monorepo blueprint, documentation scaffold, and engineering standards for a long-term production-grade implementation.

## Repository Structure

- apps/web - Next.js 16 frontend
- apps/api - NestJS backend
- packages/ui - shared UI components
- packages/config - shared tooling and linting configuration
- packages/types - shared TypeScript types
- docs - architecture, roadmap, standards, ADRs
