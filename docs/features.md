# Feature Set

## MVP Features
- Authentication and onboarding
- User profiles and company profiles
- Review and rating submission
- Search and discovery
- Notifications
- Basic moderation and reporting

## Growth Features
- Reputation scoring and trust signals
- Verification and identity assurance
- AI-generated summaries and insights
- Employer analytics dashboards
- Event-driven workflows and automation
- Integrations with external recruiting tools

## Platform Features
- Role-based access controls
- Feature flags
- Audit logging
- Observability and incident response
- Content moderation pipelines
- Multi-tenant-ready design foundations
