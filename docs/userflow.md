# User Flows

## Candidate Flow
1. User creates an account and completes a profile.
2. User browses companies and reviews.
3. User reads company profiles, compensation transparency, and interview experiences.
4. User submits a review or votes on existing content.
5. User receives notifications and updates from companies or moderation teams.

## Employer Flow
1. Company creates an employer profile and verifies ownership.
2. Company reviews applicant intent signals and interacts with talent.
3. Company responds to employee feedback and improves transparency.
4. Company uses analytics and reputation insights to improve recruiting quality.

## Admin Flow
1. Moderator reviews flagged content and abuse reports.
2. Admin confirms account verification and compliance actions.
3. Admin audits system activity and publishes policy updates.
